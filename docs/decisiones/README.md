# Registro de decisiones

consecuencias. Sirve para que dentro de un año se sepa por qué el proyecto es como es.

Una decisión no se edita una vez aceptada: si cambia, se escribe otra nueva que la sustituya
y se marca la antigua como «Sustituida por NNNN».
